# Home Workout Guide

自宅でできる基本的な自重トレーニングを、**フォーム優先・無理をしない・続けやすい**方針でまとめた個人用ガイドです。

## 収録内容

- 腕立て伏せ（Push-up）
- スクワット（Squat）
- プランク（Plank）
- 筋肉痛・張りがある日の考え方
- 初心者向けの回数・セット数の目安

## 使い方

GitHub Pagesで `index.html` を開く前提のシンプルな静的サイトです。トレーニング中は、回数よりフォームを優先します。

## 基本ルール

- 関節の鋭い痛み、しびれ、強い腫れなどがある場合は中止する。
- 筋肉の張りや軽い筋肉痛がある日は、同じ部位を強く追い込まない。
- フォームが崩れたら、そのセットは終了する。
- 呼吸を止めない。
- 痛みが続く、日常動作にも支障がある、強い脱力が続く場合は医療機関へ相談する。
