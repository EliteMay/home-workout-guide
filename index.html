00

BEFORE YOU START

「効いてる」と「痛い」を分ける

最初にここだけ確認。回数よりフォームを優先し、関節の痛みを我慢して続けません。

○

続けてよい感覚

使っている筋肉がじわっと張る、熱くなる、重くなる。最後の数回がきつくなる。

×

中止する痛み

手首・肘・肩・膝・腰などの鋭い痛み、ピリッとする痛み、しびれ、強い腫れ。

01
軽く体を動かす

その場歩き、肩回し、浅いスクワットなどを数分。準備運動だけで疲れるほど強くしません。

02
古いダンベルを確認

持ち手・プレートの大きな割れ、外れそうなガタつき、鋭いサビがある場合は使いません。

03
筋肉痛を成果にしない

翌日に筋肉痛が来なくても、トレーニングが無意味だったとは限りません。

01

STANDING / 3 KG × 2

立ってやるダンベル

肩・腕は3kgでも使いやすく、脚や背中はゆっくり動かすことで負荷を作れます。

図の見方左が開始、右が動かした後。緑のダンベルと矢印を追います。

手首が痛む場合同じ場所が痛む種目は中止。握るときは手首を前腕と一直線に。

01

ダンベルカール

力こぶ / 上腕二頭筋

12〜20回 × 2
効く場所

力こぶ（上腕の前側）。後半ほど張る・熱くなる感覚が出やすい。

  1. 足を肩幅くらいにして左右に1個ずつ持つ。
  2. 肘を体の横に固定する。
  3. 手のひらを前に向け、肩方向へ上げる。
  4. 2〜3秒かけてゆっくり下ろす。

手首や肘が鋭く痛むなら中止。

02

ショルダープレス

肩 / 上腕三頭筋

8〜15回 × 2
効く場所

肩の前〜横・二の腕の後ろ。肩関節そのものが刺すように痛むのは別。

  1. ダンベルを肩の横へ構える。
  2. お腹に軽く力を入れ、腰を反らしすぎない。
  3. ダンベルを真上へ押す。
  4. 勢いで落とさず、肩の横まで戻す。

腰が反るなら回数を減らす。

03

ベントオーバーロー

背中 / 肩の後ろ

15〜25回 × 2
効く場所

肩の後ろ〜肩甲骨まわり・上背部。腕の前側も補助で疲れることがあります。

  1. 膝を軽く曲げ、お尻を後ろへ引いて前傾。
  2. 背中を丸めず、ダンベルを真下へ。
  3. 肘を腰の後ろへ引く。
  4. 肩をすくめず、ゆっくり下ろす。

腰が痛むならその場で中止して姿勢を確認。

04

ダンベルスクワット

太もも / お尻

15〜25回 × 2
効く場所

太ももの前・後ろ・お尻。立ち上がる後半で脚とお尻がきつくなります。

  1. 左右に1個ずつ持ち、足を肩幅前後に。
  2. お尻を後ろへ引きながら膝を曲げる。
  3. 3秒かけて下がる。
  4. かかとを床につけたまま立ち上がる。

膝や腰の鋭い痛みは「効いている」感覚ではありません。

1周したら1〜2分休憩 → もう1周。最初は4種目だけでOKです。
02

SEATED WORKOUT

座ってできるメニュー

床に寝たり、立ち続けたりしたくない日に。ダンベルあり2種目、なし2種目です。

椅子の条件キャスターなし・ぐらつかない椅子。足裏が床につく高さ。ショルダープレスは背もたれがある椅子を優先。
WITH DUMBBELLS

3kgダンベルあり

重ければ両手同時にやらず、片手ずつ。

S1

座ってダンベルカール

力こぶ / 3kg × 2

10〜20回 × 2
効く場所

力こぶ（上腕の前側）。立位より反動を使いにくい。

  1. 椅子に深く座り、足裏を床へ。
  2. 左右にダンベルを持ち、腕を体の横へ。
  3. 肘の位置を変えず肩へ向けて曲げる。
  4. 2〜3秒かけて下ろす。

手首は前腕と一直線。

S2

座ってショルダープレス

肩 / 二の腕 / 3kg × 2

8〜15回 × 2
効く場所

肩の前〜横・二の腕の後ろ。肩関節の鋭い痛みはNG。

  1. 背もたれのある安定した椅子へ。
  2. ダンベルを肩の横へ、手首はまっすぐ。
  3. お腹に軽く力を入れて頭上へ押す。
  4. 勢いで落とさず肩まで戻す。

3kg×2が重ければ片手ずつ。

NO DUMBBELLS

ダンベルなし

テレビや動画を見ながらでもやりやすい脚中心の2種目。

S3

座って膝伸ばし

太ももの前

左右10〜15回 × 2
効く場所

太ももの前。脚を伸ばしたときに前側が固くなる感覚が目安。

  1. 背すじを立て、両足を床へ。
  2. 片脚の膝をゆっくり伸ばす。
  3. 伸ばした位置で1〜2秒止める。
  4. ゆっくり戻して反対脚も行う。

膝が鋭く痛むなら中止。

S4

座ってもも上げ

股関節まわり / 太もも / 体幹

左右10〜20回 × 2
効く場所

太ももの付け根〜前側。姿勢を保つためお腹にも軽く力が入ります。

  1. 椅子に座り足裏を床へ。
  2. 背すじを保ったまま片膝を上げる。
  3. ゆっくり床へ戻す。
  4. 左右交互に繰り返す。

上体を大きく後ろへ倒さない。

座ったままやるなら4種目を1周 → 1〜2分休憩 → もう1周。肩や手首が痛い日は脚2種目だけでもOK。
03–05

BODYWEIGHT BASICS

自重3種目

画像を大きく見ながら、フォームだけ先に確認します。

03 / PUSH-UP

腕立て伏せ

頭からかかとまでを1本の板みたいに保ったまま、胸を下げて押し戻す。

効く場所

胸・二の腕の後ろ。お腹と背中も姿勢を保つために使います。

  1. 手は肩幅〜少し広め。
  2. 頭からかかとまでをほぼ一直線に。
  3. 肘を真横へ開きすぎない。
  4. コントロールできる範囲まで胸を下げる。
手首が痛い場合壁腕立てや安定した高い台へ変更。それでも痛むなら腕立ては休む。
04 / SQUAT

自重スクワット

後ろに椅子があるつもりで、お尻を後ろへ引きながらしゃがむ。

効く場所

太もも・お尻。回数が増えると脚が重くなる・熱くなる感覚が出やすい。

  1. 足は肩幅前後、つま先は自然に少し外へ。
  2. 足裏全体で床を踏む。
  3. お尻を後ろへ引きながら股関節・膝を曲げる。
  4. 膝はつま先とだいたい同じ方向へ。

深さより、かかとが浮かず同じフォームで戻れることを優先。

05 / PLANK

プランク

腰を上げ下げせず、頭・背中・お尻・かかとが一本につながる姿勢をキープ。

効く場所

お腹まわり・体幹。背中や肩にも姿勢を支える疲れが出ることがあります。

  1. 肘を肩のほぼ真下へ。
  2. 頭からかかとまでをほぼ一直線に。
  3. 腰を反らさず、お尻を上げすぎない。
  4. 呼吸を続け、崩れる前に終了。
15〜30秒 × 2セット腰・首・肩に鋭い痛みが出たら終了。
06

RECOVERY

筋肉痛・張りがある日

遅発性筋肉痛（DOMS）は、慣れない運動や強い運動のあと1〜3日ほどして出ることがあります。

GO

軽く動いてよい目安

軽い張りやだるさで、日常動作とフォームに大きな問題がない。

DOWN

負荷を下げる

フォームが保てない、いつもの回数がほとんどできない、筋肉痛が強い。

STOP

中止・相談を優先

鋭い痛み、強い腫れ、しびれ、動かせないほどの脱力など。

07

HOW TO PROGRESS

3kgが軽くなってきたら

重量をすぐ買い替えなくても、まず回数と動作速度で少し難しくできます。

STEP 1

回数を少し増やす

フォームが崩れず余裕なら、まず1〜3回ずつ増やします。

STEP 2

下ろす動作を遅くする

2〜3秒かけて下ろすだけでも、3kgの負荷を感じやすくなります。

回数・セット数・動作速度を一度に全部増やさず、1つずつ調整します。
