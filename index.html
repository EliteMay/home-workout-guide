最初に見るポイント

回数よりフォーム崩れ始めたら、そのセットは終了。
強い筋肉痛は追い込まない軽く動くのはよくても、痛む部位を強く鍛え直さない。
鋭い痛みは別扱い関節の痛み・しびれ・強い腫れが出たら中止する。
呼吸を止めない力んでも、自然な呼吸を続ける。

BEFORE YOU START

始める前

いきなり限界までやらず、動きを確認してから本セットへ入る。

軽く体を動かす

その場歩き、肩回し、浅いスクワットなどを数分行い、痛みなく動ける範囲を確認する。

準備運動だけで疲れるほど強くする必要はない。

今日は軽くてもOK

寝不足、強い疲労、前回の強い筋肉痛が残る日は、回数やセット数を減らすか休む。

胸の痛み、失神しそうなめまい、いつもと違う強い息苦しさなどが出た場合は運動を中止する。

PUSH-UP

腕立て伏せ

胸・肩・上腕三頭筋を中心に使う。まずはきれいな1回を作る。

フォーム

  1. 手は肩幅〜少し広めに置く。
  2. 頭からかかとまでをほぼ一直線にする。
  3. お腹とお尻に軽く力を入れて、腰を反らさない。
  4. 肘を真横に開きすぎず、斜め後ろへ曲げる。
  5. コントロールできる範囲まで胸を下げ、床を押して戻る。

難しいときの調整

通常の腕立てで姿勢を保てないなら、安定した机や壁を使って負荷を下げる。

壁 → 高い台 → 低い台 → 床の順で、少しずつ難しくできる。

SQUAT

スクワット

深さより安定を優先する。ふらつく場合は、丈夫な机や椅子の背に手を添えて行う。

フォーム

  1. 足は肩幅前後、つま先は自然に少し外へ向ける。
  2. 足裏全体で床を踏み、かかとを浮かせない。
  3. お尻を後ろへ引きながら、股関節・膝・足首を一緒に曲げる。
  4. 膝はつま先とだいたい同じ方向へ動かす。
  5. 背中は丸めたり反らしすぎたりせず、自然な前傾を保つ。

深さの考え方

太ももが床と平行になる深さは一つの目安で、必須ではない。

かかとが浮かず、ふらつかず、同じフォームで戻れる深さを優先する。

PLANK

プランク

腹部・背中まわりを含む体幹を、姿勢を保ちながら使う種目。

フォーム

  1. 肘を肩のほぼ真下に置く。
  2. 頭・背中・お尻・かかとをほぼ一直線にする。
  3. 腰を反らさず、お尻を上げすぎない。
  4. 顔は床へ向け、首をすくめない。
  5. 呼吸を続けながら、崩れる前に終了する。

プルプルしても大丈夫？

筋肉が疲れて震えること自体は、始めたばかりでは珍しくない。

ただし腰・首・肩の鋭い痛み、しびれ、フォームを保てないほどの震えが出たら終了。

RECOVERY

筋肉痛・張りがある日

遅発性筋肉痛（DOMS）は、慣れない運動や強い運動のあと1〜3日ほどして出ることがある。

軽く動いてよい目安

軽い張りやだるさで、日常動作とフォームに大きな問題がない。

負荷を下げる

フォームが保てない、いつもの回数がほとんどできない、筋肉痛が強い。

中止・相談を優先

鋭く強い痛み、強い腫れ、しびれ、動かせないほどの脱力、非常に濃い色の尿など。

強い症状、1週間以上改善しない痛み、日常動作に支障がある状態は、一般的な筋肉痛以外の可能性もあるため医療機関へ相談する。

STARTER ROUTINE

最初のシンプルメニュー

毎回限界までやるより、同じフォームを再現できる状態で終える。

種目目安調整
腕立て5〜10回 × 2セット難しければ壁・安定した台
スクワット10〜15回 × 2セットふらつくなら支えを使う
プランク15〜30秒 × 2セット崩れる前に終了

※ 一般的な開始目安。最初は週1〜2回からでもよく、慣れてきたら主要な筋群を週2日以上動かすことが一般的な健康目標。強い筋肉痛が残る部位は無理に重ねない。

少しずつ進める

同じ回数・同じフォームが余裕をもって続けられるようになったら、まず1〜2回増やす。それでも余裕があるなら、次に少し難しいフォームへ進む。

一度に全部増やさない

回数・セット数・難しさを同時に大きく上げるより、1つずつ変えるほうが疲労やフォーム崩れを確認しやすい。

この3種目は胸・脚・体幹中心の入門メニューで、背中の「引く」動作などは含まないため、全身を完全に網羅するメニューではありません。
